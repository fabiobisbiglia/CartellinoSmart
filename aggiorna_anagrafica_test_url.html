Aggiorna anagrafica

Versione separata per verificare se il browser riesce a leggere un file Excel condiviso da SharePoint/OneDrive. La selezione di un file locale resta disponibile.

Pagina di prova: la normale pagina AGGIORNA_ANAGRAFICA non viene modificata.

1

Seleziona o collega il file di origine

Usa LISTA_MATERIALI_STOCK.xlsx oppure un file CSV con codice, descrizione e stock nelle colonne A, B e C.

Per Excel viene letto il foglio LISTA_MATERIALI_STOCK; se non è presente, viene usato il primo foglio.

OPPURE PROVA UN LINK SHAREPOINT / ONEDRIVE

Preferisci un link diretto di download. I link che aprono solo l’anteprima SharePoint potrebbero non restituire il file Excel.

Il link non viene salvato e la richiesta parte dal tuo browser verso Microsoft. Il browser può usare la sessione Microsoft già attiva, se SharePoint lo consente. Le regole CORS del tenant possono comunque bloccare la lettura.

Scarica e sostituisci il file

Scarica il risultato e sostituisci anagrafica.js nella cartella condivisa del generatore.

Il file selezionato o scaricato dal link viene elaborato nel browser: non passa da un server CartellinoSmart. Se il browser blocca l’accesso SharePoint per autenticazione o CORS, usa il pulsante Sfoglia e seleziona il file locale.
